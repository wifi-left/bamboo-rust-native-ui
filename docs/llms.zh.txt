# Bamboo Native UI

> 一个小巧的、声明式的原生 Windows UI 框架：GDI + 脏矩形渲染，
> 一个抽象了后端的绘制器，不依赖 egui/wgpu/WebView。应用负责计算控件
> 矩形；框架只绘制脏矩形并分发规范化后的输入。
> 空闲即零绘制。Rust 2024，Apache-2.0，宿主层仅限 Windows。

本文件是面向 AI 助手的精选入口。完整、自包含的
上下文文件是 `zh/ai/reference.md`；控件速查表是
`zh/ai/widgets.md`。所有链接均相对于本目录。
